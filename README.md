# warbler-app

Warbler — a mobile companion app for solo travellers in difficulty, guided by Woby.

Built with Expo (React Native + TypeScript). The design handoff this app is built from lives in `design_handoff_warbler/` — see `design_handoff_warbler/README.md` for the full spec (tokens, screens, behaviour, state). `design_handoff_warbler/Warbler v4.dc.html` is the interactive design prototype; it is a reference only, not production code.

## Run

```
npm install
npm run ios     # or: npm run android / npm run web
```
